## What's new in v1.0.9?

### 🎵 Added Music System

- **Commands:**
  - `%play (keyword)` - Initialize the music.
  - `%pause` - Pause the audio.
  - `%resume` - Resume playback after pausing.
  - `%skip` - Skip the current track.
  - `%loop (0-off | 1-one)` - Toggle loop mode.
- **How to use:**
  1. Join a voice channel first.
  2. Type `%play (keyword)`.
  3. Select your song from YouTube.
  4. Enjoy the music!

### 🛠️ Fixed `setjoin` and `setleave` commands

- Fixed an issue where `setjoin` and `setleave` did not override previous settings.
- Use `%setjoin none` or `%setleave none` to disable these features.
- New suffix supported: `{memberCount_ordinal}`.

### 📂 Folder Structure Remake

- Reorganized the folder schematic for better aesthetics and easier patching.
